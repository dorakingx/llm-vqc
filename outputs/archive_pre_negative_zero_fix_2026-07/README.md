# INVALIDATED — pre-fix outputs (generated 2026-06-23)

The figures and data in this directory were generated by `circuit_explorer.py`
**before** the 2026-07-12 fix to `state_key` (see `DECISIONS.md` and the
"Fixed bug" note in the main `README.md`).

`state_key` hashed rounded amplitudes without canonicalizing the sign of
zero. `-0.0` and `+0.0` are numerically equal but byte-distinct, so
physically identical states could receive different hash keys, inflating
every reported "unique state" count. Concretely:

- N=2 was reported as 82 unique states; the correct value is 60.
- N=3 at depth 5 was reported as 893 unique states; the correct value is 666.

Every count, trajectory curve, gate-distribution histogram, and circuit
diagram in this directory reflects the inflated (incorrect) counts and
should not be cited or reused. They are kept here only as a historical
record of the pre-fix state of the project; do not delete without checking
that nothing external references them.

Regenerate current, correct outputs with `python -m llm_vqc.main` (or the
Phase 0+ config-driven runner once available) using the fixed `state_key`.
